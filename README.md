# 📈 Learning Strategy

### 1. Learn the Concept

Understand the underlying DSA topic and common patterns.

### 2. Practice Problems

Solve problems without immediately looking at the solution.

### 3. Revisit & Revise

Re-solve important problems and record:

* Core pattern
* Key observation
* Mistakes
* Time complexity
* Space complexity
* Common variations

---

# 📝 Revision Checklist

For every important problem:

* [ ] Can I identify the pattern?
* [ ] Do I understand why the solution works?
* [ ] Can I solve it without looking at the code?
* [ ] Do I know the time complexity?
* [ ] Do I know the space complexity?
* [ ] Can I solve a variation of the problem?
* [ ] Can I recognize the same pattern in a new problem?

# ⭐ Repository Notes

* Solutions are primarily written in **C++**.
* SQL solutions are included separately.
* Problems were originally synced using **LeetSync** and are now being synced using **LeetHub**.
* The repository contains a small number of duplicate folders caused by the switch between syncing tools.
* `118-pascals-triangle` and `0118-pascals-triangle` represent the same problem.
* `242-valid-anagram` and `0242-valid-anagram` represent the same problem.
* The README uses the **actual LeetCode problem number** rather than relying on the folder naming convention.
