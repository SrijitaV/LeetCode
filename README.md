# 📈 Learning Strategy

The repository will be used in three stages:

### 1. Learn the Concept

Understand the underlying DSA topic and common patterns.

### 2. Practice Problems

Solve problems without immediately looking at the solution.

### 3. Revisit & Revise

Re-solve important problems and record the pattern, mistakes, and key observations.

---

# 📝 Revision Checklist

For every important problem, I aim to understand:

* [ ] What is the core pattern?
* [ ] Why does the solution work?
* [ ] Can I solve it without looking at the code?
* [ ] What is the time complexity?
* [ ] What is the space complexity?
* [ ] What common variations can appear?
* [ ] Can I recognize this pattern in a new problem?
